Idle Gimbal Lock 0.1.0

Engine gimbals stay neutral while their engine gives no thrust. Stock gimbals follow the
pitch/yaw/roll input even without thrust; under physics warp heavy gimballed parts then shake the
vessel. The gimbal's own lock is set for each physics step while no engine on the part is burning
and cleared right after, so it never ends up in a save; a lock set by the player is left alone.
Requires Harmony 2.2.1+.

model Claude Opus 5.5. The code, configs and documentation were generated by the AI;
