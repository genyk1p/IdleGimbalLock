# Idle Gimbal Lock

Engine gimbals stay neutral while their engine gives no thrust.

## The problem

Stock `ModuleGimbal` turns the nozzles after the pitch/yaw/roll input every physics step, whether or not its engine is burning. A nozzle without thrust gives no torque, so this does nothing useful, but it is not harmless: the gimbal's response speed is multiplied by the physics step (`gimbalResponseSpeed * TimeWarp.fixedDeltaTime`), so under physics warp the nozzles follow every twitch of the attitude controller at once. With heavy gimballed parts the vessel shakes and can get into resonance. Seen with the KSP Interstellar Extended Nuclear Lightbulb, whose gimbal moves the whole reactor (`gimbalTransformName = Reactor`), while MechJeb turned the vessel at 4x.

## What it does

A Harmony prefix on `ModuleGimbal.FixedUpdate` sets the gimbal's own lock for that one physics step when no engine on the same part is burning (throttle above 1% or thrust above 0.1 kN), and a finalizer clears it right after. With the lock, `ModuleGimbal` returns the nozzles to neutral and ignores the input. As soon as the engine burns, the gimbal works as usual.

- The lock is never left set between steps, so it never ends up in a save.
- A lock the player set by hand is left alone.
- Parts without an engine module (e.g. separate gimbal parts) are not touched.
- It works the same for MechJeb, any other autopilot and manual flying.

## Requirements

- KSP 1.12.x
- Harmony 2.2.1 or newer (`000_Harmony`)

## Installation

- **CKAN:** search for "Idle Gimbal Lock" (once it is indexed).
- **By hand:** download the zip from [Releases](https://github.com/genyk1p/IdleGimbalLock/releases) and copy `GameData/IdleGimbalLock` into the game's `GameData` folder. Install Harmony 2 as well if you do not have it yet.

Safe to add to or remove from an existing save: the mod adds no part modules and saves nothing.

## Similar mods

[AECS Motion Suppressor](https://github.com/linuxgurugamer/AECS_Motion_Suppressor) by linuxgurugamer also locks the gimbals of engines that are not running, along with control surfaces outside the atmosphere. It adds a part module to every gimballed engine, checks the fuel flow every 0.25 s and sets the gimbal lock (saved with the vessel) after a 5 s delay. Idle Gimbal Lock only does the gimbal part: the lock is applied per physics step, so it reacts at once and nothing is saved or added to parts, and a lock the player set by hand is never touched. Using both at once is pointless but harmless.

## Building

```
dotnet build src -c Release
```

The build references the game's own assemblies; the KSP install path defaults to the Steam location, override it with the `KSPDIR` environment variable or `-p:KSPDIR=...`. The DLL lands in `GameData/IdleGimbalLock/Plugins`.

## По-русски

Подвес двигателя стоит в нейтрали, пока двигатель не даёт тяги. Штатный подвес KSP поворачивает сопла по командам поворота всегда, даже без тяги. Пользы от этого нет: сопло без тяги не создаёт момента. А на физическом варпе сопла мотаются вслед за каждой командой системы ориентации, и тяжёлый корабль начинает трясти, вплоть до резонанса. Особенно это заметно на «Ядерной лампочке» KSPIE: её подвес двигает весь реактор.

Мод на каждый шаг физики, пока двигатель на этой детали не работает (дроссель ≤ 1 % и тяга ≤ 0,1 кН), включает штатную блокировку подвеса и сразу после шага снимает её. Как только двигатель зажигается, подвес работает как обычно. В сохранение блокировка не попадает. Ручную блокировку игрока мод не трогает. Работает для MechJeb, любого автопилота и ручного полёта.

Мод написан в соавторстве с **Claude Code** (Anthropic), модель **Claude Opus 5.5**: код и документацию сгенерировал ИИ, автор задал идею и требования, проверил архитектуру и протестировал в игре.
